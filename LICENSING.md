# Licensing status

The upstream Point2Roof software retains its MIT notice in `v1/Point2Roof/LICENSE`. Those terms apply to the upstream material, including its attribution/notice requirements.

A license for original Koor code and model weights has not yet been selected. This repository does not assert that all its contents, training datasets, or model weights are MIT licensed. Public availability alone does not establish reuse permissions.

The separately hosted Point2Roof synthetic dataset's applicable terms have not been established in this workflow. Confirm the data/model-release terms before assigning model-weight license metadata. Raw training datasets and pretrained weights are not included here.

Building3D lists CC BY-NC-SA 4.0 and was used only for v1 evaluation. No Building3D point clouds or annotations are redistributed here.

The small `v1/examples/demo_roof.xyz` file is an independently generated mathematical I/O fixture, not a benchmark sample. Its generation code is in the archived exporter. Original Koor material, including this fixture, shares the currently unassigned Koor licensing status.
